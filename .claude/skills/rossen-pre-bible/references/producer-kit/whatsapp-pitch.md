# Template: WhatsApp pitch to Ryan

For a fast gut check before the email. Short enough to read on a phone.

```
Ran your rubric on the last 3 months and screened against everything we've done since [month]. [List what's already ours in one line.] [N] are clean. Which work for the F1 A and F2 B?

1. *Topic name.* One or two sentences: the scam and the peg. Who did views on it and how many.
[one link, the best video]

2. *Topic name.* ...
[one link]

My order is 1, 2, 3. Full links and titles in the email if you want them.
```

## Rules

- One link per story. The strongest video.
- Lead with views. That's what Ryan weighs.
- Flag the weak one yourself ("weaker on views, strong timing").
- End with a question he can answer in one line.
