## Which version is current

Descriptions on the channel have varied. Recent live shows open the second section with "PLUS:" in caps where older ones say "Also in this episode." An earlier house style also included a help line callout (866-9-ROSSEN) and closing hashtags. Open the most recent upload of the same type and match it. When a sponsor's talking points require specific description copy or a pinned comment, that copy goes in exactly as written.

## Rules

- Write it from the transcript or the final bible, not the pitch. Shows change.
- One or two words in CAPS per paragraph, the way the channel does it.
- Don't name private individuals from body cam footage. Keep specific charges out when someone is charged but not convicted.
- Check any statistic Jeff says on tape before repeating it in the description.
